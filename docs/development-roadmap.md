# Development Roadmap

This document describes the implementation plan for Narek.

The roadmap is organized into incremental milestones, allowing the platform to evolve from a local development environment into a production-ready AI agent operating system.

It is aimed at contributors and maintainers, not at users evaluating the product — for that, see the main [README](../README.md).

## 1. Backend (Spring Boot)

- Authentication
- Agents
- Runtime

## 2. Angular

- Dashboard
- Sidebar
- Layout

## 3. Docker Compose

- PostgreSQL
- Redis
- RabbitMQ
- Ollama

## 4. Spring AI

- Ollama integration
- First working agent

## 5. RAG

- pgvector
- Embeddings
- Context retrieval

## 6. Observability

- Logs
- Metrics
- Dashboard
